# Interface art that is not MU's

Everything else under `source/interface` is decoded from MU's own `Data/Interface`. These four
buttons are not: each is MU's stone button frame (from `newui_Bt_money01` / `newui_repair_00`)
with its middle darkened and an outside icon laid in it, two states stacked (resting on top, the
held one dimmed beneath), 72 x 116. Chosen by the user on 2026-09-24.
